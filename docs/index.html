Core Experience

复杂的学习安排，
保持简单。

从记录到完成，每一步都围绕清晰的优先级、可靠的提醒和可追踪的进度展开。

✓

作业与子任务

用清单拆解大型作业，记录截止日期、提交方式与优先级，完成状态自动流转。

◷

提醒与时间块

临近截止及时通知，并按科目设置作业布置间隔；把待办转换为可执行的日程。

▧

图片附件

为每项作业保存题面、草稿或参考图片，列表与详情页均可快速预览。

⌕

搜索与智能排序

按科目、截止日期和状态组合筛选，以时间紧迫性与权重排出真正重要的任务。

⇅

ZIP 备份与同步

JSON 与附件封装为 ZIP，兼容旧版备份，并可跨设备恢复完整学习数据。

▦

桌面与移动小组件

在桌面和主屏直接查看近期作业，让下一步行动始终触手可及。
