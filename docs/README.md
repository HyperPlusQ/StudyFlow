# StudyFlow GitHub Pages

本目录为 StudyFlow 官方门户页面，可直接通过 GitHub Pages 部署。

## 部署

1. 将本仓库的默认分支设为包含 `docs/` 的分支（当前默认分支为 `macos`）。
2. 在 GitHub 仓库的 **Settings → Pages** 中选择：
   - Source：**Deploy from a branch**
   - Branch：`macos` / **/docs**
3. 保存后访问：

```text
https://hyperplusq.github.io/StudyFlow/
```

页面不依赖构建工具、外部字体或第三方脚本；`index.html` 可直接发布。
